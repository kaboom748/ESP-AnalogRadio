Since these artifacts are not present when receiving the same

# CB FM Stereo

A browser-controlled, half-duplex analog FM radio. At each station, the computer supplies the microphone, speaker, and controls over USB serial. The ESP uses its radio PHY for the over-the-air FM link. Two radios take turns transmitting on the same frequency, without a Wi-Fi association.

**Start with [CB V15 PCM12](CB_V15_PCM12/README.md).** It has one [universal HTML page](CB_V15_PCM12/CB_FM_STEREO-Universal.html) for the four firmware targets and falls back to MPX with compatible V13 and V14 firmware. Use [CB V14](CB_V14/README.md) if you want the complete MPX workflow with the browser generating and decoding the stereo multiplex.

## First radio check

1. Flash the sketch for each actual board. The release guide lists the Arduino settings. Use USB data cables and close any serial monitor or other program using the ports.
2. Open the matching HTML in desktop Chrome or Edge. For the split HTML releases, keep the scripts and artwork next to `index.html`. If the browser blocks local resources or microphone permissions, serve that entire HTML directory on loopback and open the corresponding localhost page. [Chrome Web Serial documentation](https://developer.chrome.com/docs/capabilities/serial)
3. Open **PORT** and select the local board. In **AUDIO**, choose the microphone and speaker, then prepare the microphone and grant access.
4. On both radios, set the same nominal frequency. For a 2.4 GHz test, choose **CH 07** at **2,442.3125 MHz** and start with **RX FINE** at zero. Use **MONO** for the first voice check. Set **SQ** to zero if you need to hear the ungated receiver.
5. Hold the spacebar or the on-screen microphone to transmit, then release to listen. Confirm a reply in each direction. Try **HQ** with a clean signal for stereo and RDS reception. Select the same emphasis setting on both stations.

**ROBUST** is the narrower stereo profile for MPX reception. **MONO** plays the main `L+R` channel without waiting for pilot lock. **HQ** keeps the full stereo audio passband and enables RDS decoding. On V15 PCM RX the serial audio rate stays fixed at 40 kSa/s per channel across the profiles. **RX FINE** adjusts the local receiver only. **VOL** adjusts playback and **MIC GAIN** adjusts the transmitted audio.

If speech cuts out with the **SQ** light on, lower the squelch. If you hear persistent noise or lose stereo lock, compare the same call on a second frequency. For a serial interruption, check the selected firmware, browser page, port, and cable before changing RF settings.

## RF and audio

The stereo multiplex carries `L+R` baseband audio, a **19 kHz** pilot, `L−R` on a suppressed **38 kHz** subcarrier, and optional **57 kHz** RDS data. MPX and PCM12 describe the USB serial link. With PCM12 TX the firmware creates the same on-air stereo multiplex. This makes it possible to use different serial formats at the two ends of a compatible FM radio link.

The [V15 RF comparison](CB_V15_PCM12/README.md#radio-bench-results) explains why the ESP8266 gave the lowest measured FM residual at 2.4 GHz and why the C5 is the dual-band option. The [demonstration video](exampleCB.mp4) shows the CB interface.
