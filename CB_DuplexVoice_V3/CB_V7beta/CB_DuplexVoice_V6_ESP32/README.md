# CB Duplex Voice V7 beta firmware for ESP32 Classic

Open [CB_DuplexVoice_V6_ESP32.ino](CB_DuplexVoice_V6_ESP32.ino) in Arduino IDE with **Arduino-ESP32 3.3.12**. Select **ESP32 Dev Module**, **240 MHz** and **DIO flash at 40 MHz**. Keep the sketch and its `src` directory together.

Open the [V7 beta browser app](../CB_DuplexVoice_EASY_HTML/) on the USB–UART bridge connected to **UART0 TX GPIO1 / RX GPIO3**, at **921,600 baud, 8N2**. For frequency, companding and TDD timing, follow the [beta setup](../). The supported RF band is 2.4 GHz.
