# CB Duplex Voice V7 beta firmware for ESP32-C6

Open [CB_DuplexVoice_V6_C6.ino](CB_DuplexVoice_V6_C6.ino) in Arduino IDE with **Arduino-ESP32 3.3.12**. Select **ESP32C6 Dev Module** with a fixed **160 MHz** CPU configuration. The sketch checks that SDK power management is disabled. Keep the sketch and its `src` directory together.

With the [V7 beta browser app](../CB_DuplexVoice_EASY_HTML/), select the USB–UART bridge on **UART0 TX GPIO16 / RX GPIO17**, at **921,600 baud, 8N2**. Follow the [beta setup](../) for the matching 2.4 GHz channel, companding and TDD timing.
