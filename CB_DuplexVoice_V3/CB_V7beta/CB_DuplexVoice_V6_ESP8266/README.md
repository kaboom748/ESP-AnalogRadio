# CB Duplex Voice V7 beta firmware for ESP8266

Open [CB_DuplexVoice_V6_ESP8266.ino](CB_DuplexVoice_V6_ESP8266.ino) in Arduino IDE, select your ESP8266 board and set CPU frequency to **160 MHz**. Connect through the board's USB–UART serial port. The [V7 beta browser app](../CB_DuplexVoice_EASY_HTML/) opens it at **921,600 baud, 8N2**.

This 2.4 GHz build provides Master, Slave and passive-listener roles, DPX1 audio, DPT1 telemetry and the ESP8266 hardware identifier. See the [beta setup](../) for the shared air settings.
