Technical diagnostics and operating notes

The original V22 PHY and packet format are preserved. Passive role START L does not transmit. It alternates listening to both RF slots and takes every second sample, so two voices can be mixed through the same 460,800-baud serial link.

The first received marker establishes passive slot parity; the two sources are mixed, so either initial parity still produces both voices. The "Reply channel occupied" indicator is advisory; it cannot resolve truly simultaneous requests.

The stream is mono (Voice narrowband, Music / Raw wider but not hi-fi). FM stereo, 19-kHz pilot, RDS and 75-µs emphasis are deliberately not part of this independent duplex prototype. Existing CB FM Stereo V12 remains untouched.
