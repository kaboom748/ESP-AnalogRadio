Audio Fidelity & TDD Noise Filter — V6

The amplitude compander raises weak signals before FM and restores their level after RX. It does not change the RF power, TX clock or PLL. All stations must select the same companding setting before connecting.

Active: narrow harmonic notches in playback.

The TDD filter reduces stationary switching tones at the configured slot rate and its harmonics, but also attenuates real music notes at those exact frequencies. Disable it to compare. Bench measurements use recovered audio before the notch.

20/8 · 1,500 TX bursts/s · 30,000 logical samples/s per direction.

Music / Raw requests browser echo cancellation, noise suppression and AGC OFF, and widens the mono audio filters. Use headphones, especially in Music mode. Both stations must use the same timing values (audio profiles may differ).

V6 link companding affects the on-air PCM coding: use the same choice on the Master, Slave speaker and passive monitors. TDD notch is local to the receiver; it can be toggled during listening.
Use headphones to avoid acoustic feedback. Voice mode requests browser noise suppression and echo cancellation; Music / Raw requests them OFF. Browser and microphone hardware may still process the audio.
Quiet-slot protection: Master RX stays silent when the Slave timing marker is not detected. Real audio is accepted only after a valid RF marker, so an idle RX window is no longer played as remote speech.
Prototype limitation: simultaneous Master attempts and multiple Slave join attempts can still collide; automatic distributed arbitration is not yet proven on RF hardware.

Interpretation: PASS / WARN / FAIL is based on detected tones, relative gain, noise and lost samples. BAND means an intentionally filtered voice/music frequency. PCM dBFS is not RF power in dBm; precise RF deviation, occupied bandwidth and spurs still require an SDR measurement.

The Master sees the Slave → Master measurements; the Slave sees Master → Slave. Results are stored on the receiving computer, and are not telemetered to the other computer. Technical diagnostics and operating notes

The original warm-TDD RF timings and DPX1 packet format are preserved. Passive role START L does not transmit. It alternates listening to both RF slots and now forwards every sample from each one over the 921,600-baud serial link. Each source is reconstructed at its full logical rate (30,000 samples/s at TDD 20/8) before the two sources are mixed into one playback stream at the same rate.

The first received marker establishes passive slot parity; the two sources are mixed, so either initial parity still produces both voices. The "Reply channel occupied" indicator is advisory; it cannot resolve truly simultaneous requests.

The stream is mono (Voice narrowband, Music / Raw wider but not hi-fi). FM stereo, 19-kHz pilot, RDS and 75-µs emphasis are deliberately not part of this independent duplex prototype. Existing CB FM Stereo V12 remains untouched.
