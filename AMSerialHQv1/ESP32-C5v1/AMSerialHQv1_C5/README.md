# AMSerialHQv1_C5 firmware

Arduino sketch for the **ESP32-C5** mono AM transmitter. Keep [AMSerialHQv1_C5.ino](AMSerialHQv1_C5.ino), [radio.cpp](radio.cpp), and [radio.h](radio.h) in this folder when opening the sketch. The sketch handles the USB-to-UART stream and timed envelope updates. The radio files contain the C5 RF profiles and amplitude control.

Use the [C5 setup and frequency table](../README.md) and its matching [Web Serial player](../AM_LIVE_WEBSERIAL_HIFI.html).
